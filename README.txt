Sargamiya Live Event Photographs

1. Copy the app/ folder into your existing project root (merge/replace files).
2. Run Sargamiya-Live-Photo-Highlights.sql in Supabase SQL Editor.
3. Sign in as an authenticated administrator and open /admin/highlights.
4. Upload approved event photographs; they appear in the Live page Highlights slide.
5. Preserve .env.local.

Photos up to 12 MB are accepted. Supported formats: JPEG, PNG, WebP, AVIF.
